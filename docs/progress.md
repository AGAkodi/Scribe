## Implementation started — 2026-11-25

- Added `apps/g2` based on the official starter and `services/api` with initial FastAPI routes. The glasses client includes project selection, deliberate capped recording, review and confirmation screens, plus a preliminary mode selector. The backend has single-use expiring pairing, session authentication, PCM-to-WAV conversion, Notion project/block operations, bounded lexical ranking, an OpenRouter JSON adapter, and durable pending actions.
- The OpenRouter adapter rejects source IDs absent from retrieved blocks and falls back to a transcript-only proposal on failure. The Notion write path claims an action before the external call, does not retry an uncertain outcome, and returns a receipt only after a successful response. These are development implementations, not real-service verification.
