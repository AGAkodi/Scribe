# Architecture and current implementation

The Vite TypeScript client uses the Even Hub bridge to render a text container and receive tap, scroll and PCM events. The FastAPI service accepts authenticated requests, converts bounded PCM to WAV for Deepgram, fetches project blocks from Notion, ranks lexical matches, and requests a structured OpenRouter response. It creates an immutable pending proposal in SQLite. Confirm atomically claims it before requesting a new Notion page; unknown outcomes are held for manual investigation rather than blindly retried.

Actions now carry the creating session's token hash and status/cancel/confirm enforce ownership; legacy unowned actions fail closed. Pending transcript text is stored in SQLite. Recording is stopped on exit, background, disconnect and timeout where the SDK/browser delivers the event, including late microphone-start completion. The backend checks returned source IDs and exact evidence quotes, but that is not proof that a generated statement is entailed by the quote; unverified contradiction labels are withheld. Recall and brainstorming have mode-specific instructions and bounded project-scoped client history, with suggestions kept separate from the writer's transcript.

The current code is an incomplete development slice. It lacks a production-grade distributed limiter, fully validated ambiguous-write reconciliation, production database migrations, and physical-device/end-to-end validation of the latest UX. The SQLite database must be on persistent storage for any future single-instance deployment. It is not yet safe to expose publicly.
